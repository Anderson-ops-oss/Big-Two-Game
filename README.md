# Big Two Game

A multiplayer **Big Two** (鋤大弟/大老二) card game implemented in Java, allowing players to connect to a central server and enjoy real-time gameplay with friends.

## Table of Contents
- [Features](#features)
- [Prerequisites](#prerequisites)
- [Installation](#installation)
- [How to Play](#how-to-play)


## Features
- **Multiplayer Support**: Players can connect to a server to play Big Two with others in real-time.
- **Classic Big Two Rules**: Implements standard Big Two card game logic.
- **Client-Server Architecture**: Robust networking for seamless gameplay.
- **Customizable**: Easy to extend with additional features or rules.

## Prerequisites
- Java 17 or higher
- Maven (for dependency management)
- A stable network connection for multiplayer gameplay

## How to Play
- Launch the server to host the game.
- Run the client application on each player's device.
- Connect to the server by entering the server IP and port.
- Follow the on-screen prompts to play cards according to Big Two rules.
- The game continues until a player wins by playing all their cards
